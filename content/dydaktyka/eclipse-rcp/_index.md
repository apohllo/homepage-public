[Eclipse RCP](http://www.eclipse.org/home/categories/rcp.php) to platforma
tworzenia oprogramowania posiadającego bogaty interfejs użytkownika, wyodrębniona z jednego
z najpopularniejszych środowisk programistycznych dla języka Java -
[Eclipse](http://www.eclipse.org)

Pośród licznych zalet tej platformy do najistotniejszych można zalicznyć:

-   możliwość tworzenia oprogramowania dostępnego na różne systemy operacyjne, dzięki
    wykorzystaniu języka Java
-   wykorzystanie natywnych kontrolek systemu operacyjnego, dzięki bibliotece [SWT](http://www.eclipse.org/swt/)

Dzięki tym cechom platforma Eclipse RCP staje się coraz bardziej popularna -
stanowi bowiem świetną alternatywę dla technologii .NET.

Niniejszy dział, w zamyśle autora, będzie zbiorem krótkich artykułów, wyjaśniających
jak zrealizować typowe zadania związane z tworzeniem aplikacji wykorzystującej
graficzny interfejs użytkownika (np. tworzenie menu, dodawanie akcji użytkownika,
tworzenie widoków, etc.) Zakładana jest znajomość Javy oraz
podstawowa wiedza na temat podstaw platformy RCP - czym są wtyczki, widoki, perspektywy.
